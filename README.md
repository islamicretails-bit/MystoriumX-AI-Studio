# Overview

MystoriumX AI Studio is a next-generation AI-powered platform that automatically creates professional cinematic soundtracks from videos, scripts, or creative prompts.

It combines Computer Vision, Artificial Intelligence, Digital Signal Processing, and Professional Audio Mastering into a single production-ready workflow.

Designed for:

- Documentary Creators
- YouTubers
- Film Studios
- Video Editors
- AI Content Creators
- Music Producers

# Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/MystoriumX-AI-Studio.git
```

Move into the project

```bash
cd MystoriumX-AI-Studio
```

Create Virtual Environment

```bash
python -m venv .venv
```

Activate

Windows

```bash
.venv\Scripts\activate
```

Linux/macOS

```bash
source .venv/bin/activate
```

Install packages

```bash
pip install -r requirements.txt
```

---

# Run Application

```bash
streamlit run streamlit_app.py
```
